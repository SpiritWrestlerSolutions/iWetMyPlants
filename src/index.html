Calibrate

1. Hold the sensor in dry air (or push it into dry soil) and wait until the number stops moving, then press Set dry.
2. Stand it in a glass of water up to the line on the sensor, keeping the electronics dry. Wait again, then press Set wet.
The percentage uses the saved points, so you can check it straight away.

Admin password

With a password set, changing anything on this unit asks for it. The user name is admin. Looking at readings never asks. If you forget it, hold the BOOT button for 10 seconds to reset the unit.

About this unit

Update firmware

Download the newest .bin file for this chip from the releases page, then pick it here. The unit restarts when it's done. If the new firmware fails to start, the unit goes back to this version by itself.

Restart or reset

A factory reset erases WiFi, settings and calibration, then the unit opens its setup network again. Holding the BOOT button for 10 seconds does the same.
